# Book of Colors

Farbkombinationen aus eigenen Fotos sammeln: Die App erkennt die prägenden Farben eines Bildes und legt daraus eine nummerierte Seite an, mit Farbfeldern, Farbnamen und dem Foto darunter.

**App öffnen:** https://max.does.systems/utility/bookofcolors/

Dieses Repository enthält nur die Versionshinweise ([Releases](../../releases), [CHANGELOG](CHANGELOG.md)). Der Code ist nicht öffentlich.

## Nutzung

- **iPhone:** Link in Safari öffnen, Teilen → Zum Home-Bildschirm.
- **Mac:** Link in Safari oder Chrome öffnen. Safari: Ablage → Zum Dock hinzufügen. Chrome: Installieren-Symbol in der Adressleiste. Bilder lassen sich ins Fenster ziehen oder mit ⌘V einfügen.
- Nach dem ersten Öffnen funktioniert die App auch offline.

## Daten

Seiten und Fotos bleiben im Browser auf deinem Gerät. Keine Cookies, kein Tracking, keine Anfragen an Dritte. Sicherungen legst du selbst als Datei ab, zum Beispiel in iCloud Drive.
